# Functional requirements

| ID | Requirement | Roles |
|---|---|---|
| FR01 | Create, edit, deactivate and search books (title, ISBN, publication year, edition, language, synopsis) | Administrator, Librarian |
| FR02 | Manage authors, publishers and categories | Administrator, Librarian |
| FR03 | Manage copies (accession number, location, status) | Administrator, Librarian |
| FR04 | Register and manage users and their roles | Administrator |
| FR05 | Register a loan | Librarian |
| FR06 | Register a return and calculate the fine | Librarian |
| FR07 | Reserve a book with no available copy (queue) | User, Librarian |
| FR08 | Renew a loan | User, Librarian |
| FR09 | View and settle fines | User, Librarian |
| FR10 | View movement history (users see only their own) | All |
| FR11 | Manage permissions (RBAC) | Administrator |
| FR12 | Search the catalog by title, author, category and ISBN | All |
